Pour aller plus vite

  • Une erreur dans une question : recopie la question, ou le livre et le niveau, et dis ce qui ne va pas — avec la référence si tu l'as.
  • Un bug : dis sur quel téléphone (iPhone ou Android) et ce que tu faisais juste avant.
  • Tes données : pour les voir, les corriger ou les effacer, écris-nous depuis l'adresse de ton compte. Le compte se supprime aussi seul, dans le jeu : Profil → Mon compte.
  • Un message à signaler dans un groupe : dans le jeu, un appui long sur le message, puis « Signaler ».

Beaucoup de réponses sont déjà dans les questions fréquentes et le guide du jeu. Qui édite Yada : les mentions légales.
